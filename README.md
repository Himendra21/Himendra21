## About

Java Backend Engineer focused on building secure, well-structured REST APIs with Spring Boot.

I learn by building — not by collecting frameworks. Every project I work on is an exercise in going deeper: into authentication flows, layered architecture, exception handling, and the design decisions that make backend software reliable over time.

Currently strengthening: **Spring Security internals · JWT · REST API design · DSA**

## Featured Project

### [Focus API](https://github.com/Himendra21/focus-api)

Production-style REST API built to deeply understand how secure backend systems are engineered — not as a tutorial, but as real practice.

| What | How |
|---|---|
| Authentication | JWT — stateless, signed, validated through the Spring Security filter chain |
| Authorization | Role-based access control via Spring Security |
| Architecture | Controller → Service → Repository — strict layering, no shortcuts |
| Data Transfer | DTOs + Bean Validation — no raw entity exposure |
| Error Handling | Global exception handler — consistent, structured responses |
| Persistence | Spring Data JPA + Hibernate |

`Java 17` · `Spring Boot` · `Spring Security` · `JWT` · `Spring Data JPA` · `Hibernate` · `H2` · `Maven`
