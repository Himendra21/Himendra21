## About

I am a Java Backend Engineer focused on building secure, maintainable, and well-structured backend applications with Spring Boot.

My learning style is practical: I learn by building, refining, and understanding how systems behave under real constraints. Each project helps me strengthen the fundamentals behind authentication, persistence, validation, and API design.

My current focus is Spring Security, JWT, REST APIs, backend architecture, and Data Structures & Algorithms.

---

## Engineering Principles

* Build to understand, not just to finish.
* Prefer clarity over cleverness.
* Design for security, maintainability, and scale.
* Learn the mechanism before trusting the abstraction.
* Improve through iteration and real projects.

## Featured Project

### Focus API

A production-style REST API built with Spring Boot, designed with clean structure, secure authentication, and maintainable backend engineering.

#### Highlights

* JWT authentication and authorization
* Spring Security filter chain
* Layered architecture: Controller → Service → Repository
* DTO mapping
* Bean validation
* Global exception handling
* RESTful API design
* Spring Data JPA
* Hibernate
* Static frontend integration

#### Tech Stack

Java 17 • Spring Boot • Spring Security • JWT • Spring Data JPA • Hibernate • H2 Database • Maven

**Repository:**
https://github.com/Himendra21/focus-api
