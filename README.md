## About Me

I am a Java Backend Engineer focused on building secure, maintainable, and production-style backend systems with Spring Boot.

I learn by building real software. My work is centered on understanding how backend systems actually behave — request flow, authentication, persistence, validation, and architecture — not just collecting frameworks.

My current focus is Spring Security, JWT, REST API design, backend architecture, and Data Structures & Algorithms.

---

## Engineering Principles

* Build to understand, not just to finish.
* Prefer clarity and maintainability over cleverness.
* Design with security and scalability in mind.
* Understand the system before relying on abstractions.
* Improve through iteration, feedback, and real projects.

## Featured Project

### Focus API

A production-style REST API built with Spring Boot, designed with clean architecture, secure authentication, and maintainable backend structure.

**Highlights**

* JWT Authentication & Authorization
* Spring Security filter chain
* Layered architecture: Controller → Service → Repository
* DTO mapping
* Bean validation
* Global exception handling
* RESTful API design
* Spring Data JPA
* Hibernate
* Static frontend integration

**Tech Stack**
`Java 17` • `Spring Boot` • `Spring Security` • `JWT` • `Spring Data JPA` • `Hibernate` • `H2 Database` • `Maven`

**Repository:**
https://github.com/Himendra21/focus-api
